Privacy boundary

Poliora 0.2.1 is a local application. This page describes the launch product, not a future hosted service.

The default path is local.

The dashboard binds to 127.0.0.1, and workspace data is stored in the current project's .poliora directory.

Collected locally

Poliora may store provider, model, token totals, supplied or estimated cost, workflow, customer label, timestamps, request status, and trace identifiers when the user chooses an integration.

Not required

Prompts, model replies, source code, and private transcripts are not required for cost accounting and are not collected by default.

Provider credentials

Keys used by provider SDKs or model discovery remain in the user's environment. They should never be placed in source code, a report, or a Poliora workspace file.

Public website

The launch website is static and does not receive local dashboard data. If Cloudflare Web Analytics is enabled, it measures anonymous website visits and performance; it does not receive Poliora workspace data, prompts, source code, or provider credentials.
