# Poliora Competitive Position

## Honest Answer

Poliora does have competition. Helicone, Langfuse, Portkey, and LiteLLM already
offer combinations of gateways, observability, request tracing, token-cost
tracking, budgets, caching, and team controls. Calling Poliora competition-free
would damage trust.

Poliora can still own a narrower and useful category:

> A local-first AI cost decision system for teams that use coding agents and
> multiple model providers, with a proof ledger that separates estimated,
> quality-validated, and realized savings.

## Where Poliora Is Different

| Capability | Poliora launch | Typical observability platform |
| --- | --- | --- |
| Customer usage storage | Local by default | Vendor cloud or self-hosted service |
| Requires an AI gateway | No | Often central to the product |
| Coding-tool activity | Codex and Antigravity launch paths | Usually API request tracing |
| Savings workflow | Proposed to testing to validated to rolled out | Cost charts and alerts |
| Savings claim | Modeled and realized values are separate | Often reports opportunity only |
| Client delivery | Branded standalone evidence report | Team dashboard |
| Private rates | Local override with provenance | Workspace configuration |
| First value | CSV, wrapper, or local tool hook | SDK/gateway/integration |

The defensible product is not the color palette or a long model list. Those are
copyable. The harder-to-copy asset is a growing decision history that connects
workload metadata, rate provenance, quality evidence, rollout state, and
measured financial outcome.

## Launch Customer

Start with AI agencies, automation consultancies, and small SaaS teams spending
roughly $500 to $10,000 per month across models. They have enough spend for an
optimization to matter, but often lack a dedicated FinOps team.

The launch offer is:

- Free local software for collecting and understanding spend.
- Paid setup and a first savings review.
- Ongoing monitoring and a monthly evidence report after a validated win.

Avoid selling "we will reduce every bill by 40%." Sell "we will identify,
test, and measure safe cost changes without sending your prompts to us."

## World-Class Standard

The private-pilot product is credible when:

- clean installation works on Windows and Linux;
- every number has a source, period, and confidence level;
- unpriced usage cannot silently become zero-cost evidence;
- modeled savings never appears as realized savings;
- one person can import data, understand the dashboard, test a decision, and
  export a report without developer help;
- failures are actionable and do not corrupt the local workspace;
- model catalog entries show source and verification date.

The product is not yet a world-class enterprise cloud service. It has no hosted
identity, organization permissions, SSO, audit log, or managed ingestion. That
is a deliberate launch boundary, not something to disguise.
